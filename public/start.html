당신의 술잔에 독배를 — 4대 분리 모드 시작 화면

이 페이지는 무엇인가요

4대의 컴퓨터/태블릿에서 각자 아래 버튼 중 본인 자리에 맞는 것 하나만 눌러 접속하면 됩니다. 이 페이지 자체는 그냥 링크 모음이라, 이 화면을 열어보는 것만으로는 게임 자리(장남/차남)를 차지하지 않습니다 — 마음 편히 아무 기기에서나 먼저 열어 확인해보셔도 됩니다.

총 4대가 필요합니다: 게임 화면 2대(장남용/차남용) — 독 설치·미니게임·보상을 진행합니다. 고르기 화면 2대(장남용/차남용) — 라운드마다 처소 6×6 칸을 여는 화면이며, 양쪽 처소를 나란히 보여줍니다.

1) 장남 쪽 두 기기

🎲 게임 화면 · 장남(A)셋업 · 미니게임 · 보상 🚪 고르기 화면 · 장남(A)6×6 처소 칸 열기

2) 차남 쪽 두 기기

🎲 게임 화면 · 차남(B)셋업 · 미니게임 · 보상 🚪 고르기 화면 · 차남(B)6×6 처소 칸 열기

문제가 있을 때

화면에 "이미 두 명이 접속해 있습니다"라는 문구가 뜬다면, 예전 접속이 자리를 차지하고 있는 것입니다. 아무 화면에서나 하단의 "게임 재시작" 버튼을 누르면 모두 새로 접속한 것처럼 깨끗하게 초기화됩니다.

기존 방식(컴퓨터 2대, 화면 하나 공유)으로 하시려면 → 여기로 접속하세요. 진행 상황만 지켜보려면(자리를 차지하지 않음) → 관리자 화면.
